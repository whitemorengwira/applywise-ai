# /github-showcase — Public Recruiter Showcase Skill

## Purpose
Governs the separation between the private enterprise production repository and the public recruiter-facing showcase repository.

## Two-Repository Architecture
1. **Private Production Repository**:
   - Contains full implementation, internal keys/credentials, production connection strings, and candidate application history.
   - Strictly private.
2. **Public Recruiter Showcase Repository** (`whitemorengwira/applywise-ai`):
   - Sanitized exhibition demonstrating high-calibre systems engineering:
     - Architecture & Component Diagrams
     - LangGraph Agent State Machine
     - OpenCode Zen Model Routing & Cloudflare AI Gateway
     - pgvector RAG Pipeline & Multi-Source Evidence Graph
     - Prometheus Metrics & Grafana Observability Dashboards
     - Docker multi-stage builds, Kubernetes manifests, Helm charts, and Terraform IaC
     - 100% Free-Tier Zero-Cost Governance
   - Zero secrets, zero unredacted personal keys, zero private applicant telemetry.
