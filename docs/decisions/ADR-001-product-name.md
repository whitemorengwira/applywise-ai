# ADR-001: Product Name — ApplyWise AI

## Status
Accepted

## Context
The project needs a professional SaaS product name suitable for international markets, recruiter demonstrations, GitHub repositories, and Vercel deployment. It must not resemble the reference project (JobPilot).

## Decision
Selected **ApplyWise AI** from five candidates:
- ApplyWise AI ✅ — Professional, communicates intelligence + career action, domain-friendly
- CareerForge AI — "Forge" is overused in tech products
- TalentRadar AI — Sounds recruiter-facing, not candidate-facing
- HireSignal AI — Ambiguous audience
- NexusCareer AI — Too abstract

## Consequences
- GitHub repo: `applywise-ai`
- Vercel project: `applywise-ai`
- All branding, documentation, and UI reference this name
- Future domain: `applywise.ai` (not purchased, using Vercel subdomain)
